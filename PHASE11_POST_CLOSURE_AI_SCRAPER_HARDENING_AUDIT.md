## Bugs Fixed

1. **Validation Rejection Root Cause**: Fixed false `CandidateRejected("hallucinated ingredients")` on words like "lemon" derived from item names like "Fresh Lemonade". Updated token validation to consider stem/prefix matches (`_is_trusted_ingredient_token`) so valid LLM descriptions pass strict validation.
2. **Provenance Mode Tracking**: Updated backend `service.py` to record `mode: "LLM_GENERATED"` vs `mode: "GROUNDED_FALLBACK"` explicitly in proposal line provenance.
3. **Magicpin Parser Windowing Bug**: Fixed `_delivery_window` in `scraper/magicpin/parser.py` which previously concatenated `text` and `html` and sliced away `raw.page_text` when matching HTML attribute tags. Now extracts items directly from `raw.page_text`, recovering 29 items for Brew 59 on Magicpin.
4. **Item-Scoped Generating State**: Updated `ItemQualityBoard` and `AspectRow` frontend components to scope "Generating..." and inline proposal display to the exact item field path (`proposingPath`), preventing global loading states.
5. **Existing Description Improvement Gate**: Fixed `resolve_targets` in `eligibility.py` to allow direct path improvement requests (e.g. `check_id="description_coverage"`) on items that already have existing non-blank descriptions.
